# 💖 推しログ（OshiLog）

推し活をぜんぶ記録できる、推し活サポートアプリのプロトタイプです。
アジャイル開発課題の「動くたたき台」として作成しました。チームでの要件整理・クライアント役へのデモに使うことを想定しています。

## 🌐 デプロイURL（本番環境）

**https://web-production-bd33b.up.railway.app**

ユーザー名を入力するだけで使えます（プロトタイプにつきパスワード不要の簡易ログイン）。

## ✨ 機能一覧

| 機能 | 内容 |
|---|---|
| 推し登録・管理 | 複数の推しを登録（名前・カテゴリ・推しカラー・画像）。一覧表示・編集・削除 |
| スケジュール管理＋カウントダウン | ライブ・配信・グッズ発売日などを登録。トップ画面に「次のイベントまであと◯日」を大きく表示 |
| 参戦記録・オタ活家計簿 | 日付・内容・金額・メモを記録。月別の合計金額を表示（月送りで過去も見られる） |
| グッズコレクション管理 | グッズを画像付きで登録。カテゴリ（アクスタ・CD・Tシャツ等）で絞り込み |
| 推し別貢献度の可視化 | 推しごとの支出比率を円グラフ、月別の支出推移を棒グラフで表示（rechartsを使用） |
| 簡易つぶやき投稿 | 推しへの想いを一言投稿。タイムライン形式で自分の投稿を一覧表示（SNS連携なし・アプリ内完結） |

## 🛠 技術スタック

- **フロントエンド**: React 19 + Vite 7 + TailwindCSS 4 + recharts（グラフ） + React Router
- **バックエンド**: Node.js + Express
- **DB**: PostgreSQL（Railway）
- **デプロイ**: Railway（Dockerfileビルド。Expressがフロントのビルド成果物を静的配信する1サービス構成＋PostgreSQL）
- **認証**: ユーザー名のみの簡易ダミー認証（プロトタイプのため。本格的な認証はスコープ外）

## 📁 フォルダ構成

```
OshiLog/
├── frontend/          # React + Vite + TailwindCSS
│   └── src/
│       ├── pages/     # 各画面（ホーム・推し・予定・記録・グッズ・つぶやき）
│       └── components/ # 共通レイアウト・UI部品
├── backend/           # Express APIサーバー
│   ├── server.js      # APIルート定義＋静的配信
│   └── db.js          # DB接続とスキーマ初期化（起動時にCREATE TABLE IF NOT EXISTS）
└── Dockerfile         # Railwayデプロイ用
```

## 💾 DBテーブル

`users`（ユーザー）/ `oshi`（推し）/ `schedules`（スケジュール）/ `records`（参戦記録・支出）/ `goods`（グッズ）/ `posts`（つぶやき）

全テーブルに `created_at` / `updated_at` あり。テーブルはサーバー起動時に自動作成されます（マイグレーションツール不使用）。

## 🚀 ローカルでの起動方法

Node.js 20以上と、接続できるPostgreSQLが必要です。

```powershell
# 1. 依存パッケージのインストール
cd backend
npm install
cd ../frontend
npm install

# 2. バックエンド起動（別ターミナル・DB接続先を環境変数で指定）
cd backend
$env:DATABASE_URL = "postgresql://ユーザー:パスワード@ホスト:5432/DB名"
node server.js

# 3. フロントエンド起動（開発モード。/api は localhost:3000 へプロキシされる）
cd frontend
npm run dev
```

ブラウザで http://localhost:5173 を開く。

## ☁️ Railwayへのデプロイ

```powershell
railway login          # 初回のみ
railway link           # プロジェクト oshilog に紐付け
railway up --ci -s web # リポジトリ直下で実行（Dockerfileでビルドされる）
```

環境変数は `web` サービスに `DATABASE_URL = ${{Postgres.DATABASE_URL}}`（参照変数）を設定済み。

## ⚠️ プロトタイプとしての割り切り

- 認証はユーザー名のみ（他人のユーザー名を入れると同じデータが見える）
- 画像はBase64でDBに保存（2MB上限）。本来はストレージサービスを使うべき
- テストコード・CI/CDなし（動作優先）
- 決済機能・外部SNS連携なし（金額は数値入力のみ、つぶやきはアプリ内完結）
