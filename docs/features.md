# 実装済み機能一覧（推しログ / OshiLog）

実際のコードベース（backend/server.js ほか）に実装されている機能のみを、カテゴリ別に列挙する。

## 1. 認証・アカウント

| 機能 | 説明 |
|---|---|
| ID＋パスワード認証 | メールアドレス不要。パスワードはscryptでハッシュ化保存、トークンはHMAC-SHA256署名（`userId.署名`） |
| 新規登録 | ユーザーID（1〜20字・重複チェック）＋表示名＋パスワード（4字以上） |
| クイックログイン | この端末でログインしたことのあるアカウントをタップ選択（localStorage。パスワードは保存しない） |
| ロール | 一般／管理者（is_admin）／クライアント（is_client）。初期シード: admin・client・demo |
| アカウント公開/非公開 | 非公開にすると推し友以外にプロフィール詳細が見えず、おすすめからも除外 |
| ログアウト | 認証情報削除＋Socket切断 |

## 2. 推し管理

| 機能 | 説明 |
|---|---|
| 推し登録 | 名前・ジャンル・推しカラー（8色）・画像。同名は共有マスター（oshi_master）に自動集約され「◯人が登録中」を表示 |
| 推しブラウズ | ジャンル別ブロック→ポラロイド風タイル展開。ジャンル内は登録人数の多い順（人気順） |
| 推し検索 | 名前の部分一致でジャンル横断検索。その場で登録も可能 |
| 推し詳細ページ | 登録人数・公式サイトURL・グッズURL（管理者のみ編集）・承認済みギャラリー |
| 着せ替え | 承認済み画像から「その推しの表示画像」を自分用に選択（他人には影響しない）。デフォルトに戻すことも可能 |
| 着せ替え画像の申請 | ユーザーが画像を管理者へ申請 → 承認/却下（結果はプッシュ通知） |
| 推し別の支出詳細 | 推し詳細に累計金額・月別推移グラフ・参戦記録一覧を表示（自分が登録済みの場合） |

## 3. 予定・カレンダー

| 機能 | 説明 |
|---|---|
| 3階層カレンダー | 年（12か月ミニチュア）→月（連続縦スクロール）→日（24時間タイムライン）。ズーム遷移演出付き |
| 予定CRUD | タイトル・種類6種・日付・開始/終了時刻（15分単位・終日可）・推し・メモ |
| 1日詳細の帯表示 | 時刻付き予定は開始〜終了までブロックが伸び、重なる予定は横並び。時間帯タップで開始時刻入りの予定追加 |
| 予定検索 | タイトル・メモ・推し名の部分一致 |
| 関連URL | 予定にチケットサイト等のURLを保存（http/httpsのみサーバー側で許可） |
| 予定の個別リマインド | なし/5分前/15分前/30分前/1時間前/3時間前/1日前。5分おきのジョブがWeb Pushで通知（二重送信防止付き） |
| 予定の共有 | 共有先の推し友を個別に選択。共有された予定は相手のカレンダーに色分け表示され、変更はSocketで即時反映 |
| イベント連動 | 共通イベントに参加すると予定が自動追加（取消で自動削除） |

## 4. 参戦記録・家計簿・貯金

| 機能 | 説明 |
|---|---|
| 参戦記録（支出） | 内容・日付・金額・推し・イベント紐付け・メモ。月別一覧＋月合計。登録時の判子演出 |
| 集計グラフ | 推し別貢献度のドーナツグラフ／月別支出の棒グラフ（直近6ヶ月・全期間切替）。多色パレット10色 |
| イベント別貯金 | 参加イベントごとに入金・出金を記録。残高＝入金合計−出金合計（**参戦記録の支出とは完全に別管理**） |
| 貯金目標 | イベントごとに目標額を設定。達成率の進捗バー。残高を超える出金は不可 |
| 貯金サポートAI | Anthropic API（Claude Haiku）で進捗に応じた助言・励まし。1ユーザー1日10回。キー未設定時はルールベース応答 |
| ホームの貯金表示 | 目標付きイベントの一覧＋達成率をホームの「果実」から確認 |

## 5. グッズ

| 機能 | 説明 |
|---|---|
| グッズコレクション | 画像付きポラロイド風グリッド。カテゴリ8種で絞り込み。名前・価格・推し・メモ。削除可 |

## 6. SNS・つぶやき

| 機能 | 説明 |
|---|---|
| つぶやき投稿 | 300字まで。公開範囲は「🌏 全体」「💗 同じ推しの人」の2種（サーバー側で閲覧可否を判定） |
| タイムライン | 最新100件。Socket.ioで新着をリアルタイム受信。ブロック関係の投稿は相互に非表示 |
| 削除 | 投稿者本人のみ（サーバー側で403判定） |
| プロフィール遷移 | 投稿者アイコンタップで他ユーザーのプロフィールへ |

## 7. 日記帳

| 機能 | 説明 |
|---|---|
| わたしの手帳 | ページめくりUI（1ページ=1日記）。日付・タイトル・本文・推しタグ・イベントタグ。編集・削除 |
| 公開範囲 | プライベート／全体／同じ推し／同じイベント参加者の4種（つぶやきと同じサーバー側判定ロジックを再利用） |
| みんなの日記 | 公開されている日記のフィード |
| イベント紐付け | 「思い出のイベント」として参加済みイベントに紐付け（イベント履歴からも参照可能） |

## 8. 推し友・チャット

| 機能 | 説明 |
|---|---|
| 推し友（相互承認制） | 申請→承認で成立。拒否・解除は行を残さない＝再申請可能。承認時にDMルーム自動作成（過去ルームは再利用） |
| おすすめマッチング | 同じ推しを登録している公開ユーザーをランダム表示（共通の推し名付き） |
| ID検索 | ログインIDの部分一致検索から申請（ブロック関係は除外） |
| 申請の自動拒否設定 | オンのユーザーへの申請は保存されず即拒否扱い（申請者には分からない） |
| 推し友の解除 | ブロックとは別に関係のみ解消。トーク履歴は残る |
| リアルタイムトーク | Socket.io。DM・イベントグループ共通。改行対応・1000字まで |
| 添付送信 | 画像・動画・ファイル（5MB・送信前確認モーダル・種類に応じたプレビュー表示） |
| 既読 | DMは「既読」、グループは「既読n人」。未読バッジ。既読状況はリアルタイム配信 |
| トーク一覧 | 最終メッセージ・時刻・未読数。ピン止めで最上部に固定 |
| 共有アルバム | トークルーム単位。チャットの画像を「📸保存」で保存、直接アップロードも可。リアルタイム反映。自分の写真のみ削除可 |
| ブロック（LINE方式） | 推し友関係は維持したまま、ブロック中に相手が送ったメッセージが「自分にだけ」非表示（解除後も非表示のまま）。既読も付かない。相手にはブロックが一切分からない設計。つぶやき相互非表示・おすすめ除外。判定はすべてサーバー側 |
| ブロックリスト | ブロック中ユーザーの確認・解除 |

## 9. 共通イベント・会場

| 機能 | 説明 |
|---|---|
| 共通イベント | 管理者が作成（名前・アーティスト・日付・場所・説明・画像・会場）。全ユーザーが閲覧・参加可能 |
| イベント参加 | 参加者登録＋個人カレンダーへ自動追加＋参加者専用グループトークへ自動参加 |
| 重要度 | 参加イベントごとに「ふつう/重要/最重要」を設定。カレンダー・ホーム・一覧で色分け表示 |
| ディープリンク | `/events?focus=ID` で該当イベントへスクロール＋ハイライト（通知のリンク先に使用） |
| 会場マスター | 名称・住所・緯度経度・最寄り駅・運賃メモ。管理者のみ編集。全国の著名会場約40件をシード済み |
| 地図表示 | Google Maps Embed APIで会場位置を表示（キー未設定時はGoogleマップへのリンクにフォールバック） |
| 最寄り駅ルート | Google Routes API（公共交通）で会場→最寄り駅の所要時間・距離を表示。運賃は管理者のメモを表示 |
| イベント履歴 | 参加した過去イベントの一覧（支出合計・記録数・日記数）＋紐づく参戦記録・日記の詳細 |

## 10. 通知

| 機能 | 説明 |
|---|---|
| Web Push（VAPID） | PWAのプッシュ通知。購読の自動再同期（iOSの購読失効対策）・失効購読の自動掃除 |
| アプリ内トースト | アプリ表示中はOS通知の代わりに画面上部のトーストで表示（iOSは常にOS通知） |
| 通知センター | ベル🔔→通知履歴一覧（未読強調・タップで既読化＋該当画面へ）。未読バッジは Socket で即時更新。「すべて既読」あり |
| カテゴリ別オン/オフ | 推し友申請／DM／グループトーク／イベント通知の4種。オフはPush・履歴記録の両方をスキップ |
| イベントリマインド | 参加イベントの2週間前・1週間前・3日前・2日前・前日・当日の6段階カウントダウン通知 |
| 予定リマインド | 予定ごとに設定したタイミング（5分前〜1日前）で通知 |
| その他の通知 | 推し友申請・成立／チャット新着／着せ替え審査結果／推しの新規イベント追加 |

## 11. 管理者機能（/admin・判定はすべてサーバー側）

| 機能 | 説明 |
|---|---|
| イベント管理 | 作成・編集・削除、参加者数の確認。作成時にアーティストの推し登録者全員へ通知 |
| 会場管理 | 登録・編集・削除（名称・住所・緯度経度・最寄り駅・運賃メモ） |
| 着せ替え審査 | ユーザー申請画像の承認・却下（結果を申請者へ通知）。承認時に代表画像未設定なら自動設定 |
| 推しマスター管理 | 新規追加（未登録の推しも先行登録可）・名前/ジャンル/公式URL/グッズURL/代表画像の編集 |

## 12. AI機能

| 機能 | 説明 |
|---|---|
| 貯金サポートAI | イベント貯金の進捗（残高・目標・残り日数）を渡して助言を生成。1日10回制限。フォールバックあり |
| サイト案内AI | アプリの全機能ナレッジをシステムプロンプトに持つガイドAI。全ログインユーザーが回数制限なしで利用可（AI相談FAB→/guide） |

## 13. PWA・UI/UX

| 機能 | 説明 |
|---|---|
| PWA | manifest.json＋Service Worker。ホーム画面追加でアプリのように起動（standalone・縦固定） |
| テーマカラー | 5色（ワイン/スモークブルー/セージグリーン/モーヴ/テラコッタ）。即時反映・端末保存 |
| デザイン | 「紙の推し活手帳」コンセプト（ベージュ紙色×ワインレッド×箔押しゴールド。蛍光色不使用） |
| ホームの果実の木 | 水彩風の木に機能を果実として配置。タップで拡大モーダル。昼/夜の自動切替。糸吊り演出 |
| マイクロインタラクション | 判子演出・カウントアップ・ズーム遷移・ページめくり等（すべて `prefers-reduced-motion` で無効化） |
| 引っ張って更新 | 全画面のPullToRefresh |
| ローディング/空表示 | 「取得中／0件／データあり」の3状態を全画面で明確化 |

## 実装していないもの（資料に書かないための注記）

- オフラインキャッシュ（Service Workerにfetchハンドラなし。SWはPush受信とホーム画面追加が目的）
- 画像のストレージ保存（現在はBase64でDB保存。上限2MB、チャット添付5MB、アルバム3MB）
- テストコード・CI/CD
- 決済機能・外部SNS連携
- メールアドレス・パスワードリセット
